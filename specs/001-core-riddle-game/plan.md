# Implementation Plan: Core Riddle Game

**Branch**: `001-core-riddle-game` | **Date**: 2026-03-05 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/001-core-riddle-game/spec.md`

## Summary

Build a command-line riddle game (Riddle Quest) using Python. Players can play full sessions,
list riddles, or request a single random riddle. The game loads riddles from a bundled JSON
data file, accepts text answers, and tracks score within a session. Implementation uses uv
for packaging, pytest for TDD, and keeps all logic in a simple three-layer structure (CLI →
game logic → data loader).

## Technical Context

**Language/Version**: Python 3.11+
**Primary Dependencies**: click (CLI parsing), pytest (testing) — both managed via uv
**Storage**: JSON file bundled in the package at `src/riddlequest/data/riddles.json`
**Testing**: pytest with `uv run pytest`
**Target Platform**: macOS/Linux terminal (cross-platform)
**Project Type**: CLI application
**Performance Goals**: Instant response to each answer (<100ms perceived latency)
**Constraints**: No network access; no file I/O outside project directory; self-contained
**Scale/Scope**: Single-user interactive CLI; 20+ riddles in initial dataset

## Research Findings

### Decision: click for CLI parsing
- **Decision**: Use the `click` library for CLI argument/command parsing.
- **Rationale**: click provides clean subcommand handling (`play`, `list`, `one`) with
  decorators, automatic `--help`, and is well-tested. stdlib `argparse` is also viable but
  click is simpler for subcommand dispatch.
- **Alternatives considered**: `argparse` (stdlib, but more verbose for subcommands),
  `typer` (heavier, overkill), `docopt` (less maintained).

### Decision: JSON bundled data file
- **Decision**: Store riddles in `src/riddlequest/data/riddles.json`, included as package data.
- **Rationale**: Simple, human-editable, no database needed, satisfies self-contained constraint.
- **Alternatives considered**: CSV (less structured), SQLite (overkill for 20 riddles), TOML (fine but less common for data arrays).

### Decision: importlib.resources for data file access
- **Decision**: Use `importlib.resources` to load the bundled JSON, so it works correctly
  whether the package is installed or run via `uv run`.
- **Rationale**: Robust cross-platform data file access within a Python package without hardcoding paths.

## Data Model

### Riddle

A riddle stored in `riddles.json`:

```json
{
  "question": "What has keys but no locks, space but no room, and you can enter but can't go inside?",
  "answers": ["keyboard", "a keyboard"]
}
```

Fields:
- `question` (string, required): The riddle text shown to the player.
- `answers` (list of strings, required): One or more accepted correct answers (case-insensitive match).

### Session (in-memory only)

Tracked at runtime, not persisted:
- `riddles`: list of Riddle objects selected for this session
- `score`: integer count of correct answers
- `total`: integer count of riddles answered

## CLI Contract

```text
Usage: riddlequest [OPTIONS] COMMAND [ARGS]...

  Riddle Quest - Test your wits with classic riddles!

Commands:
  play   Play a riddle session. Use --count N to limit riddles.
  list   List all available riddle questions (no answers).
  one    Get one random riddle to answer.

Options:
  --help  Show this message and exit.

play options:
  --count INTEGER  Number of riddles to play [default: all]
```
